#Social Media Sentiment Analysis

This project analyzes social media data to explore how sentiment, platform, and user engagement are related across different social networking services (SNS).

Using a social media sentiment dataset, we examine whether posts with positive, negative, or neutral sentiment show different levels of engagement and whether these patterns vary across platforms such as Facebook, Instagram, and Twitter.

#Project Objectives

The main objectives of this project are to:

Analyze the distribution of positive, negative, and neutral sentiment.

Compare user engagement across different social media platforms.

Examine the relationship between sentiment and engagement metrics.

Compare engagement levels across sentiment groups.

Determine whether differences in engagement between sentiment groups are statistically significant.

Visualize key patterns and findings using Python.

Dataset

The dataset contains social media posts from multiple platforms, including information such as:

Platform – Social media platform where the post was published.

Sentiment – Sentiment associated with the post.

Likes – Number of likes received.

Retweets – Number of times the post was shared or reposted.

Other post information – Additional variables describing the post and user activity.

The data is cleaned and prepared before analysis, including standardizing platform names and handling formatting inconsistencies.

Analysis

The project uses Python and data analysis libraries to perform:

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Sentiment distribution analysis

Platform-level engagement analysis

Sentiment × Platform comparison

Statistical hypothesis testing

Data visualization

Key Questions

This project aims to answer questions such as:

How is sentiment distributed across social media posts?

Which platforms have higher average engagement?

Does engagement differ between positive, negative, and neutral posts?

Does the relationship between sentiment and engagement vary by platform?

Are the differences in engagement between sentiment groups statistically significant?

Project Context

This project was developed as part of the 2026 NYU Data Science Bootcamp. The goal is to apply data cleaning, exploratory analysis, visualization, and statistical methods to a real-world social media dataset and communicate meaningful insights from the analysis.
